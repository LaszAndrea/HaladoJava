# ☕ Haladó Java – Gyakorlati Feladatok

Ez a repository a **Haladó Java** című egyetemi tárgy gyakorlati anyagait tartalmazza. A kurzus során mélyebb betekintést nyertünk a modern Java-fejlesztésbe, különös tekintettel a **tesztelésre**, **build rendszerekre** és **mocking technikákra**.

## ✅ Főbb témakörök

### 🧪 Tesztelés JUnit segítségével
- Egységtesztek írása JUnit 4 és JUnit 5 keretrendszerekkel
- Tesztesetek felépítése, kódlefedettség növelése
- Szcenáriók és exception tesztelés

### 🧙‍♂️ Mocking keretrendszerek
- **Mockito** használata függőségek szimulálására
- Viselkedésalapú tesztek írása
- Integráció JUnit-tal

### ⚙️ Build eszközök
- Maven projektstruktúra kialakítása
- Gradle alapú build fájl létrehozása
- Függőségek kezelése, futtatás, tesztelés automatizálása

## 📦 Követelmények

- Java JDK 11 vagy újabb
- Maven / Gradle telepítve
- IDE: IntelliJ IDEA / Eclipse (javasolt)
